# 水をやる

## やること

種をまいたマスにロボットがいる状態で、次を実行する。

```bash
ros2 service call /bot1/water std_srvs/srv/Trigger
```

足元のマスの水分が増え、次のように返事が出ればクリア。

```output
response:
std_srvs.srv.Trigger_Response(success=True, message='{{msg:srv.water.done|x=1,y=0,before=0,after=60,tank=9,max=10}}')
```

## 水分とタンク

| もの | 決まり |
|---|---|
| マスの水分 | 0〜100。1 回の水やりで 60 増える (100 まで)。時間がたつと減り、100 から 0 まで 45 秒 |
| 育つ条件 | 水分が 20 以上の間だけ育つ。20 を切ると、育つのが止まる (枯れはしない) |
| タンク | 水やり 1 回で 1 減る。最初は 10 |
| 井戸 | 左下のマス (0, 0)。ロボットが井戸の上に立つと、タンクが満タンになる |

マスは、水分が多いほど濃い茶色になる。マスにマウスを乗せると、水分の値が出る。

タンクの残りは、画面右上の「ロボット」の欄か、次のコマンドで見られる。

```bash
ros2 topic echo /bot1/tank
```

## うまくいかないとき

- **{{msg:srv.water.tank_empty}} と出る:** ロボットを井戸 (左下のマス) まで動かす。最初の場所 (マス (1, 0)) からなら、`"{linear: {x: -0.5}}"` を 2 秒ほど送ると井戸に着く。満タンになると、井戸の上に「満タン」と出る。
- **{{msg:srv.water.well}} と出る:** 井戸のマスには水をやれない。種をまいたマスへ戻る。
- **水をやったのに育たない:** 水分が 20 を切っている。もう一度水をやる。
