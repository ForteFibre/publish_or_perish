# パッケージを作る

## やること

ターミナルで次を実行する。

```bash
cd ~/src26_ws/src && ros2 pkg create tutorial_nodes
```

`~/src26_ws/src/tutorial_nodes` ができればクリア。このあとのステージで書くノードは、すべてこのパッケージに入れる。

## できるもの

`ros2 pkg create` は、パッケージのひな形を作る。

| ファイル | 中身 |
|---|---|
| `package.xml` | パッケージの名前と、使うほかのパッケージ (依存) を書くファイル |
| `CMakeLists.txt` | どのソースをどうビルドするかを書くファイル |
| `src/` | C++ のソースを置くディレクトリ (今は空) |
| `include/tutorial_nodes/` | ヘッダーを置くディレクトリ (この講習では使わない) |

package.xml と CMakeLists.txt は、ステージ 3 で書き換える。

## コマンドの意味

| 部分 | 意味 |
|---|---|
| `cd ~/src26_ws/src` | `src` に移る。パッケージは `src` の中に作る |
| `&&` | 前のコマンドがうまくいったときだけ、次のコマンドを実行する |
| `ros2 pkg create tutorial_nodes` | 今いる場所に `tutorial_nodes` というパッケージを作る |

パッケージの名前は、小文字の英字、数字、`_` で付ける。

## うまくいかないとき

`ros2 pkg create` は、実行した場所にパッケージを作る。場所を間違えると、点検の欄に次のように出る。

- **「パッケージを src の外に作った」:** ホームやワークスペースの直下で実行した。点検の欄に出る `mv ...` のコマンドで `src` の中へ動かす。
- **「パッケージの中にパッケージを作った」:** `src/tutorial_nodes` の中で、もう一度実行した。同じ名前のパッケージが 2 つになり、ビルドが止まる。点検の欄に出る `rm -r ...` のコマンドで、内側のほうを消す。
- **名前を打ち間違えた:** 農場が調べるのは `tutorial_nodes` という名前のパッケージだけ。間違えたほうを `rm -r` で消して、作り直す。
