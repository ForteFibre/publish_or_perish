# 自分のノードだけでサイコロの目を 6 にする

## やること

`auto_node` を書き足す。スタートゾーンからサイコロの前へ行き、`/robot/dice` を呼んで、目が 6 になるまで転がす。

## 説明

### 向きも合わせる

ハンドは台車の前にあるので、サイコロの方 (右、向き 0) を向く必要がある。点に「向き」も足して、向きの差にも比例した `angular.z` を送る。

```cpp
double eth = goal_th - th_;
eth = std::atan2(std::sin(eth), std::cos(eth));   // -π〜π に直す (359° 回らないように)
cmd.angular.z = std::clamp(3.0 * eth, -2.0, 2.0);  // std::clamp は <algorithm>
```

着いたかどうかは、位置の差 (2 cm 以内) と向きの差 (0.02 rad ≒ 1° 以内) の両方で見る。

### 段の種類を増やす

これからは「点へ行く」のほかに「service を呼ぶ」「アームを動かす」も順に並べる。段ごとに種類を持たせる。

```cpp
struct Step {
  enum Kind { Goto, Dice } kind;
  double x, y, th;   // Goto のとき
};
```

タイマーの中で、今の段の `kind` を見て、Goto なら点へ近づき、Dice なら転がす。

### 6 になるまで転がす

今の目は `/robot/dice_top` (Int32) で届く。Dice の段では:

1. 目が 6 なら、次の段へ。
2. 返事を待っていなければ、`/robot/dice` を呼ぶ。
3. 返事が来ても、`/robot/dice_top` に新しい目が届くまで少し (0.3 秒) かかる。待ってから 1 に戻る。

## 位置

| 順 | 段 | 中身 |
|---|---|---|
| 1 | Goto | (-3.11, -3.11)、向き 0 (スタートゾーンの中でその場で右を向く) |
| 2 | Goto | (-0.82, -3.12)、向き 0 (ハンドの真ん中がサイコロの 0.14 m 手前に来る) |
| 3 | Dice | 6 になるまで転がす |

## 手順

1. `Step` に向きと種類を足し、上の 3 段を並べる。
2. Subscriber を足す: `/robot/dice_top`。Client を足す: `/robot/dice`。
3. R を押して最初の位置に戻し、`auto_node` を起動する。
4. 目が 6 になって「課題クリア」と出れば済み。

## ヒント

<details><summary>ヒント: 0.3 秒待つ</summary>

段に入った時刻 `start_` を覚えておく。返事が来たら `start_ = now();` にして、`(now() - start_).seconds() > 0.3` になってから目を見る。

</details>

ヒントを読んでも動かないときは、書いたコードを持って講師に聞く。

## うまくいかないとき

- **サイコロを台車で押してしまう:** 点 2 の x が大きすぎる。台車の前の端は中心から 0.23 m、サイコロの左の端は x = -0.44。
- **ぐるぐる回り続ける:** 向きの差を -π〜π に直していない。
- **6 を通り過ぎて何回も転がす:** 目が届く前に次を呼んでいる。0.3 秒待つ。
