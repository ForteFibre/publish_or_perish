# 桜ボトルをつかむ

## やること

桜ゾーンにある桜ボトル (赤いキャップ) を、ハンドでつかむ。

## 位置

桜ボトルは、桜ゾーンに 3 列 × 5 段で並んでいる。手前の 3 段と奥の 2 段は離して置いてある。

| | 値 |
|---|---|
| 列 (x) | 右から -3.09, -3.24, -3.39 |
| 手前の 3 段 (y) | 1.40, 1.475, 1.55 (7.5 cm おき) |
| 奥の 2 段 (y) | 2.04, 2.115 |
| 一度につかめる範囲 | ハンドの真ん中から左右 0.11 m、前後 -0.05〜+0.07 m |

ハンドは左右に 3 本ぶんの幅がある。ハンドの真ん中を y = 1.475 に合わせると、1.40・1.475・1.55 の 3 本を一度につかめる。

## 手順

1. エリア 2 に入ったら、左 (x が減る方) の奥へ向かう。外側の木の枠と出っ張りをよけるため、`x` を **-2.65 m** にしてから奥 (y が増える方) へ進むと通りやすい。
2. Q か E で回って、左 (x が減る方) を向く。`向き` が **180°** (または -180°) になればよい。
3. `x` = **-2.78 m**, `y` = **1.475 m** に合わせる。台車の中心から 0.31 m 前がハンドの真ん中なので、ハンドの真ん中が右の列 (x = -3.09) の上に来る。
4. J でリフトを一番下 (0) まで下ろす。左上の「リフト」が 0.00 m になるまで。
5. G でつかむ。左下に「3 本つかんだ」と出る。

## うまくいかないとき

- **「ハンドの前に立っているボトルがない」:** 位置がずれている。ハンドの真ん中が列の上に来ているか、`x` と `y` を見直す。
- **「リフトが高い」:** J でリフトを 0.03 m 以下に下ろす。
- **「サイコロの目が 1 なので、これ以上は持てない」:** 1 本しか持てない。前の課題でサイコロを 6 にする (この課題は 1 本でも済む)。
- **ボトルを台車で倒した:** 台車はボトルに当たる。R で最初からやり直す。
