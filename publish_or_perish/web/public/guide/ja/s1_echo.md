# 位置を見る

## やること

別のターミナルで次を実行する。

```bash
ros2 topic echo /bot1/pose
```

ロボットの位置と向きが、次のように流れ続ける。これが出ている間にクリアになる。止めるときは Ctrl+C を押す。

```text
position:
  x: 1.5
  y: 0.5
  z: 0.0
orientation:
  x: 0.0
  y: 0.0
  z: 0.0
  w: 1.0
---
```

## コマンドの意味

`ros2 topic echo` は、topic に届いたメッセージを表示するコマンド。`ros2 topic pub` が送る側なら、こちらは受け取る側になる。

`/bot1/pose` は、農場が 1 秒に 20 回送っているロボットの位置。型は `geometry_msgs/msg/Pose`。

| 中身 | 意味 |
|---|---|
| `position` の `x` `y` | 位置 [m]。畑の左下の角が (0, 0)。1 マス = 1 m なので、`x: 1.5` `y: 0.5` はマス (1, 0) の真ん中 |
| `position` の `z` | 高さ。農場では使わないので、いつも 0 |
| `orientation` | 向き。クォータニオンという 4 つの数 (`x` `y` `z` `w`) で表す。畑の x の向きを向いているときは `z: 0.0` `w: 1.0`。回ると `z` と `w` が変わる |

ロボットを動かしながら見ると、`x` と `y` が変わっていくのが分かる。

### topic を調べるほかのコマンド

| コマンド | 分かること |
|---|---|
| `ros2 topic list` | 今ある topic の一覧 |
| `ros2 topic info /bot1/pose` | 型と、送り手と受け手の数 |
| `ros2 topic hz /bot1/pose` | 1 秒に何回届いているか |

## うまくいかないとき

- **何も出ない:** 農場が動いていないか、農場と `ROS_DOMAIN_ID` が違う。`ros2 topic list` に `/bot1/pose` が出るか確かめる。
- **一度クリアになったあと止めた:** 止めてもクリアは消えない。
