# ロボットを動かす

## やること

農場を起動したターミナルとは別のターミナルを開き、次を実行する。

```bash
ros2 topic pub -r 10 /bot1/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.5}}"
```

bot1 が畑の右 (x の向き) へ進み始める。2 m 進めばクリア。止めるときは Ctrl+C を押す。

## コマンドの意味

`ros2 topic pub` は、topic にメッセージを送り続けるコマンド。ロボットは `/bot1/cmd_vel` に届いた速度で動く。

| 部分 | 意味 |
|---|---|
| `-r 10` | 1 秒に 10 回送る |
| `/bot1/cmd_vel` | 送る先の topic の名前 |
| `geometry_msgs/msg/Twist` | メッセージの型。速度を表す型 |
| `"{linear: {x: 0.5}}"` | メッセージの中身。前へ 0.5 m/s。書かなかった値は 0 になる |

`Twist` の中身は次のとおり。向きはロボットから見た向き。

| 書き方 | 意味 | 一番速い値 |
|---|---|---|
| `linear: {x: 0.5}` | 前へ [m/s] (負の値で後ろへ) | 1.5 |
| `linear: {y: 0.5}` | 左へ [m/s] (負の値で右へ) | 1.5 |
| `angular: {z: 1.0}` | 左回り [rad/s] (負の値で右回り) | 3.0 |

組み合わせるときは `"{linear: {x: 0.5, y: 0.3}}"` のようにカンマで並べる。

### 送り続ける理由

ロボットは、最後に速度を受け取ってから 0.5 秒たつと止まる。通信が切れたロボットが走り続けないようにする、実機と同じ安全のしくみ。

そのため、0.5 秒より短い間隔で送り続ける。`-r 10` なら 0.1 秒ごとに届く。`-r` を付けないと 1 秒に 1 回になり、ロボットは 0.5 秒進んでは止まるのを繰り返す。

## うまくいかないとき

- **動かない:** topic の名前の打ち間違い (`/bot1/cmd_val` など) が多い。画面右下の「配線」を開くと、受け手のいない topic に警告が出る。
- **柵にぶつかって止まった:** 畑の外へは出られない。`x: -0.5` にすると後ろへ戻る。
- **斜めに進む、回り続ける:** `angular` を送ると向きが変わったまま残る。`angular: {z: -1.0}` で戻すか、斜めのまま進めてもよい (進んだ距離は数える)。
- **進んでいるのに数が増えない:** 数えるのは `ros2 topic pub` (CLI) で動かした距離だけ。自分で書いたノードが同じ topic に送っていると数えない。
