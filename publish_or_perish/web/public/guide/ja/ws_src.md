# ワークスペースを作る

## やること

ターミナルで次を実行する。

```bash
mkdir -p ~/src26_ws/src
```

ホームに `src26_ws` ができ、その中に `src` ができればクリア。

## ワークスペースとは

ROS 2 では、自分で書くプログラムを**パッケージ**という単位にまとめ、パッケージを**ワークスペース**というディレクトリに置く。この講習のワークスペースは `~/src26_ws`。

ワークスペースの中は、次のように分かれる。最初に作るのは `src` だけで、残りの 3 つはビルドしたときに colcon が作る。

| ディレクトリ | 中身 | 作るもの |
|---|---|---|
| `src/` | パッケージのソース (自分で書くもの) | 自分 |
| `build/` | ビルドの途中のファイル | colcon |
| `install/` | ビルドしてできた実行ファイルなど | colcon |
| `log/` | ビルドのログ | colcon |

## コマンドの意味

| 部分 | 意味 |
|---|---|
| `mkdir` | ディレクトリを作る |
| `-p` | 途中のディレクトリ (`src26_ws`) がなければ、それも作る。もうあってもエラーにしない |
| `~/` | ホームディレクトリ (`/home/<ユーザー名>/`) |

## うまくいかないとき

- **名前を打ち間違えた:** 点検の欄に「ワークスペースの名前が違う」と出て、名前を直すコマンド (`mv ...`) が出る。それをコピーして実行する。
- **`src` を作り忘れた:** `src26_ws` だけではクリアにならない。もう一度上のコマンドを実行する (`-p` があるので、2 回実行しても困らない)。
