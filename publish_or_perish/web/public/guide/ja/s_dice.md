# ボタン 3 で、自分のノードがサイコロを転がす

## やること

`semi_node` に、ボタン 3 の動きを足す。ボタン 3 を押したら、service `/robot/dice` を呼ぶ。

台車はキーでサイコロの前 (x -0.85, y -3.11, 向き 0°) まで動かしておく。

## 説明

段は 1 つだけ (呼ぶ → 返事を待つ)。前の 2 つの課題と同じ書き方で、`step_` を 21 にするなど番号を分ける。

目が 6 になるまで、ボタン 3 を何回か押す。今の目は `/robot/dice_top` (Int32) で受け取れるので、「6 になるまで自分で何回も呼ぶ」ようにもできる (自動の課題で使う)。

## 手順

1. Client を足す: `/robot/dice`。
2. ボタン 3 を受けたら: `/robot/dice` を呼ぶ。返事の関数の中で、返ってきた `message` を `RCLCPP_INFO` で表示する。
3. ビルドして起動し、キーでサイコロの前へ行って 3 を押す。ターミナルに次のように出れば済み (目の数は例)。返事の文は英語で返る。

```output
[INFO] [1730000000.123456789] [semi_node]: {{msg:match.dice.done|before=1,after=5}} [{{msg:match.src.player}}]
```

## うまくいかないとき

- **{{msg:match.dice.far|dist=0.35,reach=0.2}} と出る:** 台車の位置。ハンドの真ん中 (台車の中心から 0.31 m 前) がサイコロから 0.2 m 以内に来るようにする。
- **X キーで転がした:** キーは数えない。R で戻してから 3 で転がす。
