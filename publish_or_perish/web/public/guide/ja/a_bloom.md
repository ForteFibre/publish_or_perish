# 自分のノードだけで 3 分以内に満開宣言をする

## やること

`auto_node` だけで、R を押してから 3 分 (180 秒) 以内に満開宣言をする。試合と同じ時間。

## 説明

段の種類は前の課題でそろっている。あとは段を全部並べる。2 往復で 12 本を 1〜12 番に置き、最後に合図 (`signal`)。

段の数が多いので、「桜ゾーンでつかむ」「共通ゾーンに置く」を関数にして、段を足していくとよい。

```cpp
void fetch(double y, std::vector<double> columns);   // 段 y の、columns の列をつかむ段を足す
void deliver(std::vector<int> zones);                // zones の共通ゾーンに 1 本ずつ置く段を足す
```

| 往復 | つかむ段 (ハンドの真ん中の y) | 列 (ハンドの真ん中の x) | 置く共通ゾーン |
|---|---|---|---|
| 1 回目 | 1.475 | -3.09, -3.24 | 1〜6 |
| 2 回目 | 2.08 | -3.09, -3.24, -3.39 | 7〜12 |

- 列の x に 0.31 を足したところに台車の中心を置く (向き π)。
- 2 回目は、つかんだあと向き π のまま y 1.6 まで下がってから右を向く。奥の段の近くで回ると、上の木の枠 (y 2.32) に台車の角が当たる。
- 共通ゾーン n の真ん中の y: 1 番は -2.29、n 番 (2〜12) は -1.77 + 0.5 × (n − 2)。

## 手順

1. `fetch` と `deliver` を書いて、サイコロ → fetch → deliver → fetch → deliver → call("signal") と並べる。
2. R で戻して起動する。右のパネルの「この回の操作」に、台車も機構も「自分のノード」だけが出ていることを確かめる。
3. 3 分以内に「満開宣言」と出れば済み。

## ヒント

<details><summary>ヒント: 時間が足りないとき</summary>

- 速度の頭打ちを上げる (1.0 → 1.2 m/s)。比例の係数を上げる。
- 着いたかの判定をゆるめすぎると、ハンドの位置がずれてつかめない。つかむ・置く直前の点だけ厳しくする手もある。
- 解答例 (速さの頭打ち 1.2 m/s, 比例の係数 2.5) は、1 回目を置き終わるまで約 45 秒、満開宣言まで約 95 秒。

</details>

ヒントを読んでも動かないときは、書いたコードを持って講師に聞く。

## うまくいかないとき

- **満開宣言にならない:** 右のパネルの「数えない」の理由を見る。ボトルが倒れて 1 マス抜けると、その上のマスは数えない。
- **3 分を過ぎた:** 時間は R を押したときから数える。起動の前に R を押す。
